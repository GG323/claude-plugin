## Project

ASP.NET Core 8 web API for a small web shop: sign-in, orders, and nightly CSV exports for the finance team. Tests use xUnit. Database: PostgreSQL through Dapper; migrations are plain SQL files in `db/migrations/`, applied in order by the deploy pipeline.
