## How to run

`dotnet test tests/Shop.Tests/Shop.Tests.csproj --logger trx --results-directory TestResults`, the same command CI runs.

## Environments and data

Unit tests only: no database or network. Orders are built in each test with synthetic SKUs and prices.

## Fixtures

None: each test builds its own `Order` with `OrderOf`.

## Conventions

One test class per production class, named `<Class>Tests`; test names read `Situation_Result`.
